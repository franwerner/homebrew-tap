# homebrew-tap

Homebrew formulae for [orb-ai](https://github.com/franwerner/orb-ai).

```bash
brew install franwerner/tap/orb-ai
```

`franwerner/tap` resolves to this repository by Homebrew's naming convention.

Formulae under `Formula/` are written here by orb-ai's release workflow on every
tagged release, with that release's asset URL and checksum. Nothing in this
repository is edited by hand.
